Recommendations for Coral maintainers

  • Add an id (and securityidentifier) column to user-returning functions so rows chain naturally (F3).
  • Honor LIMIT on nested value arrays, or document that row limits don't apply inside value (F9).
  • Remove/remap the 3–4 catalog-bug routes (sites listitems non-endpoint, getByPath arg requirement, team getgroup, drive-as-list permissions).
  • Document Graph option constraints (top on installedApps, search/filter on messages) so spec users stop passing them (F10).
  • For the delegated-context 412 family and the "AAD accounts" 400 family, add guidance that these require application permissions or a non-AAD identity (F6/F7).
