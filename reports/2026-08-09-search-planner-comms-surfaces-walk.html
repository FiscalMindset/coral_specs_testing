Recommendations for Coral maintainers

  • Expose filter as an optional arg on planner_plannerplan_planner_listplans and planner_plannertask_planner_listtasks; forward to Graph as $filter so the tables aren't permanently 405. (F-new-1)
  • Surface Graph's code field (and ideally requiredScopes) in Coral's error wrapper so consumers can route failures automatically: 403 UnknownError → re-consent, 403 Application is not registered in our store → notify admin, 400 with HTML body → retry-with-backoff. (F-new-2, F-new-3)
  • Add Search.Read.All (or External.Item.Read.All) to the Coral app's delegated grant and re-consent to unblock the 4 Search list endpoints. The zero-arg GET /search 404 is Graph-side and stays; the list endpoints should become reachable. (F-new-6)
  • Document the new sites_baseitem_sites_listitems as a function (with site_id arg) in any re-run of v6 — the v6 finding is now stale. (F-new-4)
