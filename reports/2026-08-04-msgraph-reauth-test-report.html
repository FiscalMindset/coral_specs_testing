Technical details: Why tokens expire▶

Microsoft's OAuth2 access tokens have a configurable lifetime. For interactive flows:

  • Default access token lifetime: 1 hour (3600s)
  • Default refresh token lifetime: 90 days (rolling for active use)
  • Keychain OAuth flow (interactive): Stores BOTH tokens, auto-refreshes
  • Device code flow: Can include offline_access scope for refresh tokens, but Coral's keychain isn't updated without interactive flow
  • az CLI token: 1 hour access, no refresh, manual re-login required

To extend token lifetime in Entra:

  1. Go to Entra admin portal → Applications → App registrations → Coral
  2. Manifest → set "accessTokenAcceptedVersion": 2 and configure token lifetime policies
  3. Alternatively use Conditional Access with "Sign-in frequency" set to 30 days
