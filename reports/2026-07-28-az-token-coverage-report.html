Notes & Anomalies ▶
  • 83 TABLE_NOT_FOUND: Tables registered in manifest.yaml (and listed in information_schema) that return "Table not found" at query time — likely a DuckDB foreign table registration issue.
  • 400_BADREQUEST (181): Many endpoints require parameters (id, $select, $filter) not sent in a simple SELECT * LIMIT 1. These may work with real parameterized queries.
  • Missing me_*, teams_*, users_*, places_* coverage: Many delegated-scope-only endpoints need an OAuth token with specific scopes like User.Read, Mail.Read, Teams.Read, etc.
  • Previous "universal 403" was wrong: The earlier failed run omitted the microsoft_graph_v4. schema prefix, causing DuckDB to look in the default schema.
  • 32-scope OAuth URL was generated for a broader test if needed.
