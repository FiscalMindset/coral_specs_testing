About this project

Context & ground rules

What this is

Paid QA of the Microsoft Graph v4 Coral source for withcoral. Each report runs a real coral CLI against a live AAD tenant and verifies results against Microsoft's own Graph API and OpenAPI spec.

Where reports live

Raw reports (HTML + markdown) are committed in /reports and served on GitHub Pages. This hub is a read-only index over them — it never rewrites a report.
