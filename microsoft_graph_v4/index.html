HIGH — List Endpoint Flattening Broken

All ~497 LIST-type tables return the raw OData envelope (odata_count, value) instead of flattened entity rows. Users must manually unwrap results.

MEDIUM — BETWEEN Column Lookup Bug

The BETWEEN operator fails with valid column names — the column name lookup mechanism is broken.
